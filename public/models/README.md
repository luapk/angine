# GLB assets

Drop your three GLB files into this folder, exactly named:

```
guitar.glb
drums.glb
pyramid.glb
```

Each one will be auto-fitted into a unit sphere on load, so the source files can be any reasonable scale. Multi-mesh GLBs work fine.

If a file is missing, the visualizer renders a primitive fallback (icosahedron / box / tetrahedron) so you can still test the system.
